# Contributing to Nexus Planner

Thank you for your interest in contributing!

## Workflow
1. Fork the repo and create your branch from `main`.
2. Follow Conventional Commits for all commit messages.
3. Ensure all tests pass before opening a PR.
4. Keep PRs focused - one feature or fix per PR.

## Code Style
- TypeScript strict mode enabled
- ESLint + Prettier enforced on commit via husky

## Reporting Bugs
Open a GitHub Issue with the bug template and include reproduction steps.
